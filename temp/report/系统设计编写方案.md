# 文档二：系统设计 编写方案

## 第1章：子系统架构设计

### 1.1 系统架构图

用Mermaid语法展示三层架构 + Common基础设施层：

```mermaid
graph TB
    subgraph "表示层 (Controller Layer)"
        UC[UserController]
        QC[QuestionController]
        EC[ExamController]
        SC[ScoreController]
    end

    subgraph "业务逻辑层 (Service Layer)"
        US[UserService]
        QS[QuestionService]
        ES[ExamService]
        SS[ScoreService]
    end

    subgraph "数据访问层 (Repository Layer)"
        UR[UserRepository]
        QR[QuestionRepository]
        ER[ExamRepository]
        SR[ScoreRepository]
    end

    subgraph "Common 基础设施层"
        RT[Result&lt;T&gt;]
        PR[PageResult&lt;T&gt;]
        BE[BusinessException]
        GEH[GlobalExceptionHandler]
        JU[JwtUtil]
        JAI[JwtAuthenticationInterceptor]
        RR[RequireRole]
        WMC[WebMvcConfig]
    end

    UC --> US
    QC --> QS
    EC --> ES
    SC --> SS

    US --> UR
    QS --> QR
    ES --> ER
    SS --> SR

    US -.-> SR
    UC -.-> JU
```

架构说明：
- **表示层（Controller Layer）**：接收HTTP请求，参数校验，调用Service，返回统一Result<T>响应。4个Controller对应4个业务模块。
- **业务逻辑层（Service Layer）**：核心业务逻辑，事务控制，Entity↔DTO转换，跨Repository协调。4个Service实现各模块业务规则。
- **数据访问层（Repository Layer）**：继承JpaRepository，提供基础CRUD + 自定义查询方法。4个Repository对应4张核心表。
- **Common基础设施层**：横切关注点，包括统一响应封装、全局异常处理、JWT认证与权限控制、Web配置。

**M04 DTO（13个）**：

- UserExamHistoryVO(examName, all, accuracy, submitTime)

### 2.6 Common层

| 类名 | 职责 |
|---|---|
| Result\<T\> | 统一API响应封装，含code/message/data，提供success()/error()静态方法 |
| PageResult\<T\> | 分页响应封装，含content/totalElements/totalPages/page/size，提供of()转换方法 |
| BusinessException | 业务异常类，含code/message，继承RuntimeException |
| GlobalExceptionHandler | 全局异常处理器，@RestControllerAdvice，处理BusinessException/MethodArgumentNotValidException/Exception |
| JwtUtil | JWT工具类，提供generateToken()/parseToken()/validateToken()/getUserId()/getName()/getType() |
| JwtAuthenticationInterceptor | JWT认证拦截器，preHandle()验证Token，检查@RequireRole权限 |
| RequireRole | 自定义注解，标记方法所需角色权限 |
| WebMvcConfig | WebMvc配置，注册拦截器+静态资源映射 |

## 第5章：数据库表结构设计

### 5.1 用户表 user

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|---|---|---|---|---|
| id | INTEGER | PK, AUTOINCREMENT | — | 主键 |
| name | TEXT | NOT NULL, UNIQUE | — | 用户名 |
| password | TEXT | NOT NULL | — | 密码（BCrypt哈希） |
| type | TEXT | NOT NULL | 'student' | 用户类型(student/teacher/admin) |
| status | INTEGER | NOT NULL | 1 | 状态(1=启用, 0=禁用) |

索引：idx_user_name(UNIQUE), idx_user_type

### 5.2 题目表 question

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|---|---|---|---|---|
| id | INTEGER | PK, AUTOINCREMENT | — | 主键 |
| type | TEXT | NOT NULL | — | 题目类型(SingleChoice/MultipleChoice/Judge/Fill/Essay) |
| context | TEXT | NOT NULL | — | 题干 |
| img | INTEGER | NOT NULL | 0 | 是否带图(1=是, 0=否) |
| answer | TEXT | NOT NULL | — | 答案JSON(按type适配5种结构) |
| use | INTEGER | NOT NULL, CHECK>=0 | 0 | 被抽中次数 |
| correct | INTEGER | NOT NULL, CHECK>=0 AND <=use | 0 | 被回答正确次数 |

索引：idx_question_type, idx_question_use

answer JSON结构（5种）：
- SingleChoice: `{"version":1, "correctOption":"A", "options":["A","B","C","D"]}`
- MultipleChoice: `{"version":1, "correctOptions":["A","C"], "options":["A","B","C","D"]}`
- Judge: `{"version":1, "correct":true}`
- Fill: `{"version":1, "blanks":["went","goes"]}`
- Essay: `{"version":1, "reference":"参考答案", "keywords":["关键点1"], "scoreRule":"按要点给分"}`

### 5.3 考试表 exam

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|---|---|---|---|---|
| id | INTEGER | PK, AUTOINCREMENT | — | 主键 |
| exam | TEXT | NOT NULL | — | 考试名称 |
| status | TEXT | NOT NULL | 'draft' | 状态(draft/publish/running/done) |
| starttime | TEXT | NOT NULL | — | 开始时间(ISO 8601) |
| endtime | TEXT | NOT NULL, CHECK>starttime | — | 结束时间(ISO 8601) |
| question_sum | TEXT | NOT NULL | — | 题目汇总JSON快照 |

索引：idx_exam_status, idx_exam_time(starttime, endtime)

question_sum JSON结构：
```json
{
  "version": 1,
  "items": [
    {"questionId": 123, "score": 5, "type": "SingleChoice"},
    {"questionId": 124, "score": 10, "type": "MultipleChoice"}
  ],
  "totalQuestions": 2,
  "totalScore": 15
}
```

状态机：draft ↔ publish → running → done

### 5.4 分数表 score

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|---|---|---|---|---|
| id | INTEGER | PK, AUTOINCREMENT | — | 主键 |
| user | INTEGER | NOT NULL, FK→user.id | — | 考生ID |
| exam | INTEGER | NOT NULL, FK→exam.id | — | 考试ID |
| all | INTEGER | NOT NULL, CHECK>=0 | — | 总分 |
| detail | TEXT | NOT NULL | — | 答题明细JSON |

约束：UNIQUE(user, exam) — 一人一考仅一条记录
索引：idx_score_user, idx_score_exam

detail JSON结构：
```json
{
  "version": 1,
  "items": [
    {"questionId": 123, "userAnswer": "B", "correctAnswer": "B", "score": 5, "isCorrect": true},
    {"questionId": 124, "userAnswer": ["A","C"], "correctAnswer": ["A","D"], "score": 0, "isCorrect": false}
  ],
  "summary": {"correctCount": 1, "totalCount": 2, "accuracy": 0.5}
}
```
