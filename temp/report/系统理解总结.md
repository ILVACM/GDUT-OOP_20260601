# 系统理解总结

## 1. 系统定位与目标

本系统是一个面向高校场景的**英语在线学习系统**，旨在为英语教学提供从题目录入、组卷发布到在线考试与成绩分析的全链路数字化支撑。系统以 Spring Boot 4 + Vue 3 为技术底座，采用前后端分离架构，覆盖教师出题组卷、学生在线答题、自动判分与学情分析等核心教学环节，实现英语考试流程的闭环管理。

## 2. 角色划分与权限体系

系统定义了三种角色，权限逐级递进：

- **student（学生）**：自助注册，参加考试，查看个人成绩与错题集，权限最小化，聚焦学习侧。
- **teacher（教师）**：负责题库管理、手动/自动组卷、考试发布与撤回、简答题评卷及统计报表查看，覆盖教学管理全流程。
- **admin（管理员）**：拥有全部权限，并额外承担用户管理职责，属于系统运维角色。

权限控制通过自定义 `@RequireRole` 注解 + JWT 认证拦截器实现，在 Controller 层声明式拦截，简洁高效。

## 3. 核心业务流程

系统围绕"出题→组卷→考试→判分→统计"五大环节展开：

1. **出题**：教师录入五种题型（单选/多选/判断/填空/简答），支持批量导入。
2. **组卷**：手动选题或自动随机抽题，生成 JSON 快照式试卷，确保考试期间题目不受后续修改影响。
3. **考试**：考试状态机驱动（draft→publish→running→done），系统按时间窗自动判定状态流转，学生在线答题。
4. **判分**：客观题自动判分，简答题由教师人工评卷，兼顾效率与灵活性。
5. **统计**：提供考试报表、题目分析、学生错题集等多维度数据，辅助教学决策。

## 4. 技术架构特点

- **三层架构 + Common 基础设施层**：Controller/Service/Repository 分层清晰，Common 层提供统一 `Result<T>` 响应封装、全局异常处理、JWT 认证拦截等横切关注点，避免重复造轮子。
- **JWT 无状态认证**：Token 由 JwtUtil 生成/解析，拦截器统一验证，天然支持水平扩展。
- **DTO 严格隔离**：Entity 禁止直接暴露给前端，Service 层统一转换为 VO/Record，杜绝 JSON 循环引用与敏感字段泄露。
- **考试状态机**：四态流转模型保证考试生命周期可控，时间窗自动判定减少人工干预。

## 5. 数据模型设计亮点

- **单表 + JSON 设计**：question.answer 用 JSON 适配五种题型的差异化结构，exam.question_sum 以快照方式存储组卷结果，score.detail 记录答题明细，在关系模型中优雅实现了半结构化数据的灵活存储。
- **4 表独立设计**：核心表之间无 JPA `@ManyToOne`/`@OneToMany` 关联，仅 score 表通过物理外键引用 user 和 exam，从根本上规避了 N+1 查询问题，同时保持了查询的简洁性。
- **SQLite 轻量部署**：选用 SQLite 作为持久层，零配置嵌入式运行，契合中小规模教学场景的部署需求。
