## 1. 预置条件

### 1.1 软件环境

| 组件 | 最低版本 | 推荐版本 | 用途 |
|------|----------|----------|------|
| JDK | 21 | 21 LTS | 后端编译与运行 |
| Maven | 3.9+ | 3.9.x | 后端依赖管理 |
| Node.js | 20.19.0 或 >=22.12.0 | 22 LTS | 前端编译与运行 |
| npm | 10+ | 最新稳定 | 前端包管理 |
| IDE | 支持 Trae 插件 | Trae IDE | Agent 协作环境 |

### 1.2 Agent 平台

| 要求 | 说明 |
|------|------|
| 支持 workspace rules | Agent 需支持 `.trae/rules/` 目录规则注入 |
| 支持 spec 文档驱动 | Agent 需能读取 `.trae/specs/` 中的 spec.md/tasks.md/checklist.md |
| 支持文件读写 | Agent 需具备 Read/Write/Edit 工具能力 |
| 支持命令执行 | Agent 需能运行 mvn/npm 等构建命令 |

## 2. 新项目部署步骤

### 2.1 目录结构初始化

在新项目根目录下创建以下结构：

```
新项目根目录/
├── wiki/                    # 知识库（必须）
│   ├── 00-INDEX.md          # 项目总索引
│   ├── 01-Global-Standards.md  # 全局规范
│   ├── 02-Data-Dictionary.md   # 数据字典
│   ├── modules/             # 业务模块文档
│   └── references/          # 技术参考
├── .trae/                   # Agent 规则与规格（必须）
│   ├── rules/               # 规则集
│   │   └── 开发指导.md      # AI 协作核心规则
│   └── specs/               # 任务规格
│       ├── 阶段名称/
│       │   ├── spec.md      # 需求规格
│       │   ├── tasks.md     # 任务清单
│       │   └── checklist.md # 检查清单
├── backend/                 # 后端工程
│   ├── src/main/
│   ├── src/test/
│   └── pom.xml
├── frontend/                # 前端工程（可选）
├── scripts/                 # DDL 脚本
├── data/                    # 数据库文件
└── temp/                    # 临时输出
    ├── outputs/             # 最终成果
    └── intermediates/       # 中间文件
```

### 2.4 配置模板

#### backend/application.yaml 模板

```yaml
server:
  address: 0.0.0.0
  port: 8080

spring:
  application:
    name: backend

  datasource:
    url: jdbc:sqlite:${user.dir}/../data/your_database.sqlite
    driver-class-name: org.sqlite.JDBC
    hikari:
      maximum-pool-size: 5
      minimum-idle: 1
      connection-init-sql: |
        PRAGMA foreign_keys = ON;
        PRAGMA journal_mode = WAL;
        PRAGMA synchronous = NORMAL;
        PRAGMA busy_timeout = 5000;
        PRAGMA temp_store = MEMORY;

  jpa:
    database-platform: org.hibernate.community.dialect.SQLiteDialect
    hibernate:
      ddl-auto: validate
    properties:
      hibernate:
        format_sql: true
        show_sql: false
        globally_quoted_identifiers: true
        jdbc:
          time_zone: UTC
          batch_size: 30
        order_inserts: true
        order_updates: true

logging:
  level:
    org.hibernate.SQL: INFO
```

## 5. 迁移路径（从 SQLite 到 MySQL/PostgreSQL）

如果新项目需要更换数据库，按以下步骤操作：

| 步骤 | 操作 |
|------|------|
| 1 | 修改 `application.yaml` 中的 `datasource.url` 和 `driver-class-name` |
| 2 | 替换 `database-platform` 为对应方言 |
| 3 | 移除 `connection-init-sql` 中的 PRAGMA 语句 |
| 4 | 调整 DDL 脚本（AUTOINCREMENT → AUTO_INCREMENT/SERIAL） |
| 5 | 调整 Entity 主键策略（IDENTITY → 对应数据库策略） |
| 6 | 更新 `02-Data-Dictionary.md` 中的类型映射表 |
| 7 | 更新 `wiki/references/` 中的数据库优化文档 |
